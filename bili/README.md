# bili —— 家里那间「刷B站」的屋子

这台子是给**家里这一条鱼**用的：每天到点自己去 B 站逛一圈，把候选落成日报，再用家里的阳台把她叫醒去挑。
原来是独立插件 `dsh-bili-ximeng`，2026-11-04 并进来的。

## 文件

| 文件 | 干什么 |
|---|---|
| `index.js` | 路由（`/dsh-world/bili/*`）、定时器、日报、私信提醒、阳台叫醒 |
| `py/bili.py` | 登录：出二维码、查扫码结果、查登录态、登出 |
| `py/feed.py` | 取料：搜关键词、抓字幕、抓几条高赞评论 → `room\刷B站\<日期>\候选.json` 和 `候选.md` |
| `py/im.py` | 私信：会话列表、和某人的最近 30 条、发一条 |
| `py/report.py` | 把挑出来的视频整理成日报 JSON（给我自己用，面板的「最近日报」读的是 `.md`） |
| `py/dm_test.py` | 发一条测试私信，排查用 |

Python 解释器默认 `D:\AstrBot\venv\Scripts\python.exe`，要改就在家配置的 `bili.pythonPath`。

## 东西放哪

- **登录态**：`room\B站\cookie.json`（跟着房间一起备份，别搬进插件目录）
- **配置**：`room\B站\config.json`（面板上改的写这里；家配置 `bili` 那一节是种子/默认值，文件覆盖它）
- **今天自动刷过没有**：`room\B站\auto.json`，重启不会又刷一遍
- **产出**：`room\刷B站\<日期>\候选.md|.json`（7 天窗）和 `room\刷B站\<日期>.md`（日报，永久留）

## 关于定时

不是闹钟，是插件自己每分钟看一眼时间：到点（或到点以后机器才醒）就跑一轮，一天只跑一次。
世界停了、或者面板上把这一页关掉，定时器和私信轮询一起停。
